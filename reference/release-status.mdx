- Native XLM asset contract: `CDLZFC3SYJYDZT7K67VZ75HPJVIEUVNIXF47ZG2FB2RMQQVU2HHGCYSC`.
- Namespace application fee: `50000000000` base units, with 7 decimals = **5,000 XLM**.

The [namespace fee configuration transaction](https://stellar.expert/explorer/testnet/tx/6bb169c931a2802dd3419729f24e3d11c382b6b2d19fb2e59fd77a8933badc0e) sets the upfront escrow policy. Award pays the recipient; rejection and stuck cancellation return 100%; withdrawal and expiry return 80%. Settlement may create protected pull credit if delivery fails. See [claim outcomes](/concepts/claiming-a-namespace).

A **username** fee is separate. A namespace owner can configure free claims or a flat XLM amount paid directly to their G treasury, atomically with issuance and complete payment instructions. There is no username approval escrow or mandatory annual ownership charge. The bounded holder renewal has no separate username renewal fee. Network execution, storage and restoration costs remain separate. See [automatic claiming](/owner/automatic-claiming).
