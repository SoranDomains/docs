## SDK versions

The prepared versions are Lookup **0.5.0**, Holder **0.3.0**, Owner **0.5.0** and MCP **0.5.0**. Publication is in progress and must be verified separately from contract deployment. These versions target `@stellar/stellar-sdk >=17 <18`.

Universal Lookup is the new default read path. Until your installed package contains the verified new preset, provide the matching explicit Registry/Lookup/Primary/network configuration from this page. Missing Lookup configuration throws `CONFIG`; it never silently selects direct Resolver reads. Deliberate direct mode only supports the compatible native path.
