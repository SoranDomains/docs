These versions target `@stellar/stellar-sdk >=17 <18` and the current deployment; older packages do not implement the new muxed ABI or its current preset. The [contract ABI](/api/onchain-resolution), [HTTP payment API](/api/resolution) and [hosted MCP](/agents/access) remain separate integration options.

Universal Lookup is the default read path. Missing Lookup configuration throws `CONFIG`; it never silently selects direct Resolver reads. Successful version negotiation selects the matching V1 or V2 ABI; unknown versions and failures never trigger a downgrade. Deliberate direct mode supports compatible native Resolvers.
