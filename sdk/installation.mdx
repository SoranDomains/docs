These pages target Lookup 0.6.0. Its testnet preset matches the current Registry, Lookup and Primary in the deployment record.

```bash
npm install @sorandomains/lookup@0.6.0 @stellar/stellar-sdk@^17
```

The supported Stellar SDK peer range is `>=17 <18`. The package is ESM with TypeScript types and supports Node, browsers and workers.

## Universal mode is the default

```ts
import { Soran } from "@sorandomains/lookup";

const soran = new Soran({
  network: "testnet",
  registryId: deployment.registryId,
  lookupId: deployment.lookupId,
  primaryId: deployment.primaryId,
  rpcUrl: deployment.rpcUrl,
  passphrase: deployment.passphrase,
  reverseNamespaces: ["nova"],
  hintUrl: deployment.apiUrl,
  timeoutMs: 10_000,
});
```

`deployment` represents your verified network configuration. Universal Lookup is the shared read entry point; per-namespace Registrar and Resolver addresses are discovered on chain, not hard-coded in the app.

A network without a Lookup pin fails with `CONFIG`. `new Soran({ network: "testnet" })` selects this package version's bundled deployment. Lookup 0.6.0 matches the current testnet release; explicit configuration lets you pin a reviewed deployment independently of package updates. Changing Registry or network passphrase prevents inheriting a Lookup or Primary pin from an unrelated preset. There is no supported mainnet preset until a reviewed deployment exists.

In universal mode, a provided `primaryId` is an extra check against `Lookup.primary()`. `primaryId: null` disables the Primary feature. Omitting it for a custom deployment lets Lookup's configured anchor determine the Primary read.

## Explicit direct compatibility mode

```ts
import { Soran } from "@sorandomains/lookup";

const direct = new Soran({
  registryId: deployment.registryId,
  rpcUrl: deployment.rpcUrl,
  passphrase: deployment.passphrase,
  resolutionMode: "direct",
  primaryId: deployment.primaryId,
});
```

`lookupId: null` also explicitly selects direct mode. Direct mode discovers **native** Resolvers and checks Registry, Registrar authority and payment version. A successful native payment version 1 selects the direct payment ABI; version 2 additionally checks destination version 2 and supports M. Failed or unknown capability reads never select an older ABI. It has no fallback to older address-only implementations. `lookup`, `namespaceMetadata` and `nameMetadata` require universal mode.

## Other options

| Option | Purpose |
| --- | --- |
| `reverseNamespaces` | Ordered namespace candidates for reverse probing; default empty |
| `hintUrl` | Optional indexed discovery for namespace candidates, holdings and history |
| `resolverCacheTtlMs` | Direct-mode routing cache lifetime; default 30,000 ms, `0` disables it |
| `timeoutMs` | Per-chain-read wait bound; a larger aggregate can take longer; does not cancel the underlying request |

HTTPS is required except for allowed local-development hosts. Names are checked for ASCII before lowercasing, and whitespace is not trimmed. Malformed configuration or name input must be corrected rather than retried as an absent record.

See [reference](/sdk/reference) for methods, result types and typed failures.
