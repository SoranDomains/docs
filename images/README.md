# Illustration assets

These original SVG diagrams explain namespaces, registration, profiles, network addresses, subnames and resolution. They use a shared flat design in light and dark themes, with separate mobile compositions to keep labels readable.

The profile portrait is a generated fictional person. It is embedded in the profile SVGs so they remain self-contained.

The Stellar emblem uses the official vector paths from the [Stellar brand resource hub](https://stellar.org/brand-resources). “Stellar” is a trademark of the Stellar Development Foundation. All rights reserved. Soran is independently developed and has no SDF sponsorship or endorsement.

Names and abbreviated addresses in the diagrams are illustrative.
