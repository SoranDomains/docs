Soran turns a name such as `alice.yourbrand` into a Stellar payment destination. An organization claims a **namespace** such as `yourbrand`, then lets people claim names in its own app using rules stored on chain.

A name can resolve to a classic **G account**, a **G account with a memo**, a **muxed M address**, or a **C contract address**. The address and any required routing information stay together on chain. Try [the live examples](/live-examples) to see each type.

## One on-chain read entry point

Wallets, explorers and apps read **Universal Lookup**. It finds the namespace's current Registrar and Resolver through the Registry, then returns the validated result. The SDK wraps this contract; a Soran database is not required for resolution.

The **namespace owner** sets issuance rules. The **holder** owns a name under those rules. The **recipient** receives payments. These can be different people: for example, you can hold a name that points to an exchange account with your deposit memo.

## Claim once, then issue names

A public namespace application costs **5,000 XLM on testnet**, paid upfront into escrow. It passes through a public objection window before it can be awarded. [The outcome determines the payment or refund](/concepts/claiming-a-namespace).

Username claims are separate. The namespace owner can offer free claims or set a flat XLM price paid to their treasury. Once enabled, the contract processes eligible claims without a separate owner approval for each person. Optional eligibility rules can restrict claims to the organization's users.

## Read the ownership policy

Soran has no mandatory annual ownership fee. Each namespace's policy determines whether names can expire, be reclaimed or become permanent. Network and storage costs still apply.

A zero expiry does not by itself mean a name is permanent. [Ownership guarantees](/concepts/ownership-guarantees) explains what holders can rely on, and what owners can change.

Start with the [current testnet addresses and package versions](/reference/release-status). Mainnet is not available yet.
