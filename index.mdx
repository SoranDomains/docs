Soran is the **Soroban Registry for Assigned Names**. A business owns a namespace such as `yourbrand` and issues names such as `alice.yourbrand`. A name can carry a Stellar destination, an optional payment memo and holder-authored profile records.

<Note>
These docs describe the September 2026 implementation and the fresh testnet contracts deployed on 5 September. The public app, API and hosted MCP serve this setup. Start with [release status](/reference/release-status) for contract addresses, published package versions and hosted endpoints.
</Note>

## One on-chain read entry point

Wallets, explorers and other contracts read **Universal Lookup**. It follows the Registry to each namespace's current Registrar and Resolver and can return a complete address-and-memo payment instruction. The SDK wraps that contract; you can use its ABI directly without a Soran SDK or database.

| Contract | Responsibility |
| --- | --- |
| Registry | Namespace ownership, routing and permanence attestations; no upgrade entry point |
| Allocator | Public namespace claims, objections and upfront fee escrow |
| Registrar | A namespace's issuance, holders, policy, generations, expiry and transfers |
| Resolver | A namespace's on-chain addresses, optional memos, text and scoped reverse names |
| Primary | An address's elected cross-namespace display name |
| Universal Lookup | Shared on-chain read entry point, with governed code upgrades |

Namespace ownership, a name's holder and its payment recipient are separate roles. An exchange deposit name can resolve to the exchange's account plus a customer memo without making that account the name holder.

Payment destinations support classic G accounts, G accounts with ID/text/hash memos, and C contract addresses without a memo. Direct muxed M addresses are not currently supported. See [address types and examples](/concepts/payment-destinations).

## Claim once, then issue names

Public namespace claims pay an upfront fee into the Allocator and pass through a public objection window. The fresh testnet release charges 5,000 XLM, with the receiving wallet published in the deployment record. The proposed mainnet fee is 5,000 USDC, with no mainnet deployment claimed. [Claim outcomes](/concepts/claiming-a-namespace) determine payment or refund.

That claim fee applies to the **namespace**, not each name issued under it. Current issuance contracts add no Soran per-name claim fee or mandatory annual renewal charge. Stellar transaction and storage costs still apply. A namespace owner may operate a timed or commercial service under its disclosed policy. Optional hosted billing and marketplace features are separate.

## Read the ownership policy

A name can be reclaimable, finite-term, or protected by a completed permanence lock. A zero expiry alone is not proof of permanence. Even permanent names need storage upkeep, and their holders can change their records. [Ownership guarantees](/concepts/ownership-guarantees) explains the exact boundaries.
